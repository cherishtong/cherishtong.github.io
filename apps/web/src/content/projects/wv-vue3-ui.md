## 关于

WuWei Design 是一个以「无为」为精神内核的 Vue 3 组件库实验。它把中国传统文房美学翻译成一套现代 UI 语言：墨色为骨、纸张为底、朱砂为血，再混入一点液态玻璃和功能性微动效。

## 这个站从它借了什么

- 纸张与墨色的明暗关系
- 宫墙红作为唯一强调色
- 细边框、小圆角、克制的阴影
- 字距拉开的大写微标签
- 文档侧边栏的活跃态

新站没有直接复用它的 Vue 组件，而是把这套视觉语言重写成 Astro + 原生 CSS 的静态壳。组件库本身仍然保留在 Vue 生态里。
