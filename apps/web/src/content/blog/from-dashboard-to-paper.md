原来的首页是一个 Vue dashboard，整个页面 `client:load`，卡片、表格、侧边栏都很热闹。但它更像一个后台管理系统，而不是一个可以长期写字的地方。

这次重构，我先把“展示”往后放，把“阅读”放到前面。

## 一张纸的优先级

- 正文的宽度、字号和行高，比首屏动画重要
- 一张卡片的边框和留白，比渐变和阴影重要
- 一个页面里朱砂出现的次数，比朱砂本身重要

所以新站的外壳全部是 Astro 静态组件，只有真正需要交互的地方才引入框架。博客、文档和项目详情先保证打开就能读，Lab 再单独承载 React、Vue 这些实验。

## 山水作为背景

背景是一层固定的山水：群山、长城、六十四卦与日月。它不是一张图片，而是 CSS 渐变加内联 SVG，所以可以随主题切换，也可以整体替换。

正文区用一层半透明的宣纸压住背景，保证阅读；页面两侧和首屏仍然能看到山水的呼吸。这样既保留了“祖国的山山水水”，也不会让背景抢走文字。

## 下一步

- 把文档和项目也接进 Content Collections
- 加入 Pagefind 搜索
- 在 Lab 里放 React 和 Vue 的第一批示例
- 把背景组件做成可切换的变体：山河、长城、城楼、卦象

先把纸铺好，再慢慢写。
